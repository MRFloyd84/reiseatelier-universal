# Reiseatelier (universell)

Reiseplanungs-App für jede Art von Reise – Rundreise, Städtetrip, Badeurlaub, Wandern, Kreuzfahrt. Mehrere Reisen pro Gerät, Route mit Karte, Reiseplanung, Einreise-Checkliste für deutsche Staatsangehörige, Notfall-Tab mit Notrufnummern aller 249 Länder und Gebiete, Reisetagebuch mit Fotos und Countdown. Läuft komplett im Browser, offline-fähig und als App installierbar (iPhone, Android, Windows, Mac).

Alle Reisedaten bleiben auf den Geräten. Mitreisende gleichen über eine Abgleich-Datei je Reise in einem geteilten Ordner ab (iCloud Drive, Google Drive, OneDrive, Dropbox, Nextcloud). Im Repository liegt nur die leere App.

Installation, Abgleich und Funktionen: [ANLEITUNG.md](ANLEITUNG.md).
