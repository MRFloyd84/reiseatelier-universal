# Reiseatelier (universell)

Reiseplanungs-App für jede Art von Reise – Rundreise, Städtetrip, Badeurlaub, Wandern, Kreuzfahrt. Mehrere Reisen pro Gerät, Route mit Karte, Reiseplanung, Einreise-Checkliste für deutsche Staatsangehörige, Notfall-Tab mit Notrufnummern aller 249 Länder und Gebiete und deutschen Vertretungen live vom Auswärtigen Amt, Fußgänger-Navi für Städtetrips (Spaziergänge mit mehreren Punkten, Sehenswürdigkeiten in der Nähe aus Wikidata, Abbiegehinweise, Sprachansagen, Offline-Kartenpakete), Packliste, Reisekasse mit Währungsumrechnung und Ausgleich, Reisetagebuch mit Fotos und Countdown, Import aus Kalender (.ics), Tabelle (.csv) oder Text, Export als Kalenderdatei. Deutsch und Englisch, heller und dunkler Modus. Läuft komplett im Browser, offline-fähig und als App installierbar (iPhone, Android, Windows, Mac).

Alle Reisedaten bleiben auf den Geräten. Mitreisende gleichen über eine Abgleich-Datei je Reise in einem geteilten Ordner ab (iCloud Drive, Google Drive, OneDrive, Dropbox, Nextcloud) – auf iPhone und Android. Im Repository liegt nur die leere App.
